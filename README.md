# YuriiHTML — GitHub Pages Editor Template

Цей невеликий проєкт дає простий інтерфейс для введення HTML/CSS/JS та миттєвого перегляду.
Ідеально підходить як стартовий template для розміщення на GitHub Pages.

## Як використовувати локально

1. Розпакуй архів.
2. Відкрий `index.html` у браузері.

## Як опублікувати на GitHub Pages

1. Створи новий репозиторій на GitHub (наприклад `yuriiHTML`).
2. Додай файли і зроби commit & push.
3. У налаштуваннях репозиторію → **Pages** вибери гілку `main` (або `gh-pages`) та папку `/ (root)`.
4. Зачекай кілька хвилин — сайт буде доступний за адресою:
   `https://<твій-нік>.github.io/<repo-name>/`

## Ідеї для розширення

- автозбереження у файл/інтеграція з Gist
- необмежені шаблони, бібліотека прикладів
- збереження версій (history)
